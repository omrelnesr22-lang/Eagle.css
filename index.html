01

مقدمة إلى CSS

CSS هي اختصار لـ Cascading Style Sheets، وتقوم بوصف طريقة عرض المحتوى والمظهر الخاص به: الخط، الألوان، ومكان العناصر في الصفحة. تتكوّن من Properties نُنسّق من خلالها الصفحة. 

h1 {
  color: red;
  font-size: 11px;
}
/* selector { property: value; declaration } */
02

ثلاثة أماكن لكتابة كود CSS

لكل طريقة استخدام مختلف — من الأسرع للتجربة إلى الأفضل للمشاريع الكبيرة.

الأقل تفضيلاً

Inline CSS

يُكتب داخل عنصر الـ HTML مباشرة، ما يجعل كود CSS مختلطًا بكود HTML في نفس السطر.

<h1 style="color:blue;font-size:30px;">I Love Almdrasa</h1>
داخل الصفحة

Internal CSS

يُكتب في نفس صفحة HTML، داخل وسم <style> بمنطقة الـ head.

<style>
  h1 {
    color: blue;
    font-size: 30px;
  }
</style>
الأفضل عمليًا

External CSS

يُكتب في ملف CSS منفصل، ويُربط بملف HTML عبر وسم link.

<link rel="stylesheet" href="file_name.css">
03

تنسيق النص — Text Styling

font-size

حجم النص.

font-size: 10px;

font-family

نوع الخط المستخدم للنص.

font-family: Arial, Helvetica, sans-serif;

text-transform

تحويل النص لأحرف كبيرة أو صغيرة.

text-transform: uppercase;

line-height

تحديد المسافة بين الأسطر.

line-height: 1.5;

text-align

تحديد اتجاه محاذاة النص.

text-align: center;
04

المحددات — Selectors

دمج المحددات — Combining Selectors

عند تكرار نفس الخواص لأكثر من عنصر، نجمع المحددات ونفصل بينها بفاصلة بدلًا من التكرار.

h1, h2, h3 {
  text-transform: uppercase;
  line-height: 1.5;
  text-align: center;
}

/* h1 بداخل div معيّن فقط */
div h1 { color: red; }

Class و Id

Class تُستخدم لأكثر من عنصر، ويمكن للعنصر حمل أكثر من class. أما Id فهو فريد لعنصر واحد فقط في الصفحة.

/* Class → نقطة قبل الاسم */
.class_name {
  text-transform: uppercase;
}

/* Id → علامة # قبل الاسم */
#id_name {
  line-height: 1.5;
}
05

نظام الألوان

ثلاث طرق شائعة لتحديد الألوان في CSS.

RGB Model

خليط من ثلاثة ألوان: أحمر، أخضر، أزرق — كل قناة من 0 إلى 255.

color: rgb(244, 179, 63);

RGBA

نفس نظام RGB مع قناة رابعة لدرجة الشفافية (0 إلى 1).

color: rgba(0, 255, 255, 0.3);

Hexadecimal

الأكثر استخدامًا لاختصاره — من 0 إلى FF لكل قناة لونية.

color: #00ffff;
06

العناصر الزائفة — Pseudo Classes

كلمات تُضاف إلى محدد لتحديد حالة خاصة للعنصر.

first-child

أول عنصر فرعي (child) من العنصر الأب (parent).

.element:first-child { color: #fff; }

last-child

آخر عنصر فرعي من العنصر الأب.

.element:last-child { color: #fff; }

nth-child()

تحديد العنصر برقم ترتيبه.

.element:nth-child(2) { color: #fff; }

first-of-type()

أول عنصر من نوعه بين عناصر متشابهة.

p:first-of-type { color: #fff; }
07

تنسيق الروابط — Hyperlinks Styling

  • a:link — الروابط العادية التي لم تُزَر بعد.
  • a:visited — الروابط التي زارها المستخدم.
  • a:hover — عند مرور الماوس فوق الرابط.
  • a:active — عند النقر على الرابط (النشط).
رابط تجريبي مرّر الماوس فوقه لترى a:hover

أولويات المحددات — Specificity

عند تعارض الخواص، تفوز الأولوية الأعلى. اضغط كل مستوى لترى ترتيبه في «عين النسر».

#id ID Selector01
.class / :pseudo Class أو Pseudo-class02
p, div, li Element Selector03
* Universal Selector04

إذا تكرر نفس الـ Id، تُنفَّذ خصائص آخر Id مكتوب.

.author { font-size: 18px; }
#author { font-size: 20px; } /* يفوز — Id أقوى من Class */
p, li { font-size: 22px; }
09

نموذج الصندوق — Box Model

يحدد كيفية ظهور العنصر وحجمه الفعلي في الصفحة.

Margin
Border
Padding
Content
Margin — المسافة بين العنصر والعناصر المحيطة به.
Border — يحيط حول العنصر بالكامل.
Padding — المسافة بين المحتوى والحدود.
Content — أي محتوى: نص، صورة، فيديو.
/* العرض الفعلي */
Actual width =
  left border + left padding
  + width + right padding + right border
/* الطول الفعلي */
Actual height =
  top border + top padding
  + height + bottom padding + bottom border
/* Margin لا يُحسب ضمن الحجم الفعلي */
10

Padding & Margin

Padding — الهامش الداخلي

المساحة بين محتوى العنصر وحدوده.

padding-top: 10px;
padding-right: 10px;
padding-bottom: 10px;
padding-left: 10px;

/* مختصرة: أعلى يمين أسفل يسار */
padding: top right bottom left;

Margin — الهامش الخارجي

المساحة بين العنصر والعناصر المحيطة به.

margin-top: 10px;
margin-right: 10px;
margin-bottom: 10px;
margin-left: 10px;

/* توسيط الصفحة: هامش تلقائي يمين ويسار */
margin: 0 auto;

أنواع الصناديق — Display

Block

block
block

inlineinline
display: inline;

123

12

Position

التدفق الطبيعي — Normal Flow

الوضع الافتراضي (Default)، يعتمد على ترتيب العنصر في الصفحة كما هو مكتوب.

position: relative;

التموضع المطلق — Absolute

يُخرج العنصر من التدفق الطبيعي ولا يلتزم بأي قوانين، ويبحث عن أقرب أب يملك position: relative ليلتزم بحدوده.

position: absolute;
top: 5px;
left: 5px;
13

العناصر الزائفة — Pseudo Elements

::first-letter

تحديد أول حرف في العنصر.

h2::first-letter { font-size: 30px; }

::first-line

تحديد أول سطر في العنصر.

p::first-line { color: red; }

::after

إدخال محتوى (نص/أيقونة) بعد محتوى العنصر.

p::after { content: "Trending"; }

::before

إدخال محتوى (نص/أيقونة) قبل محتوى العنصر.

p::before { content: "Trending"; }
14

النسخة العربية — RTL

لعمل نسخة عربية من الصفحة، نتعامل مع HTML كما هي ونغيّر فقط dir="rtl" ونربطها بملف CSS. المشاكل الشائعة (مثل اتجاه الهوامش) تُحل بتحويل margin-left إلى margin-right والعكس.

<html dir="rtl">

/* في ملف CSS */
[dir=rtl] selector {
  /* تُنفَّذ فقط عندما تكون الصفحة rtl */
}
